# AI-Powered Travel & Policy Assistant

An AI-powered assistant for answering fictional corporate travel-policy questions using RAG, tool calling, memory, and agentic workflows.

## Project Goals

- Answer travel-policy questions using company policy documents
- Retrieve relevant policy information using RAG
- Check employee eligibility using tools
- Validate travel requests against policy rules
- Calculate reimbursable amounts
- Maintain conversation context for follow-up questions
- Expose the assistant through a Flask web application

## Technologies

- Python
- Pandas
- Flask
- LangChain
- LangGraph
- Sentence Transformers
- FAISS / Chroma
- LLM API / Ollama
- MCP
- Git / GitHub
